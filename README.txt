VR Fitness Training Project

Prerequisites:

- Windows 11/ MacOS/Linux or any OS of your preference that is able to run MySQL Workbench.
-MySQL Workbench
-MySQL Server


How to use:
-Connect to your MySQL server.
- Open the script in MySQL Workbench.
- Click lightning Bolt to run the entire script. This will create a database, tables, sample records and etc.


Script function:

This sql script creates a database that organizes information for a VR Fitness training service. It stores the members, trainers, workouts, exercises, and actual completed workouts. It links these together so that you can see which members do each workout, what exercises each workout uses, and what workouts a member has completed.
It then populates it with fake sample records and shows you them by running queries against it. For example, one query shows Alex's history of workouts.
